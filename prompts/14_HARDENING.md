# Prompt 14 - Hardening

Perform a security and reliability review against:
- anonymous abuse;
- authz bypass;
- reporter deanonymization;
- alert field leakage;
- duplicate delivery;
- webhook replay;
- attachment abuse;
- stale subscription rules;
- cross-organization data access;
- provider failure;
- queue retry duplication;
- unsafe AI outputs.

Add tests for every issue found. Update relevant docs.
